Architecture

Large Language Models

The transformer architecture that underpins every major LLM — the self-attention mechanism in full mathematical detail, positional encoding, scaling effects, and the alignment stack that makes models safe to deploy.

From RNNs to Transformers

Prior to 2017, language models used Recurrent Neural Networks (RNNs). An RNN processes tokens sequentially, maintaining a hidden state hₜ:

h_t = tanh(W_h h_{t-1} + W_x x_t + b) [RNN cell]

The problem: this sequential computation is inherently serial — you cannot compute h₄₀ before h₃₉. Training is slow. Worse, gradients must flow backwards through hundreds of time steps — they vanish. Long-range dependencies (a pronoun referring to a subject 500 words earlier) are essentially unlearnable.

The Transformer (Vaswani et al., "Attention Is All You Need", 2017) eliminated recurrence entirely. Every position in a sequence attends to every other position simultaneously via the self-attention mechanism. Training is fully parallelisable. Long-range dependencies are modelled in a single attention step regardless of distance.

Scaled Dot-Product Attention

The core operation of a transformer. Given a sequence of token representations packed into a matrix X ∈ ℝ^{n×d} (n tokens, d dimensions), three linear projections produce Query, Key, and Value matrices:

Q = X W_Q W_Q ∈ ℝ^{d × d_k} K = X W_K W_K ∈ ℝ^{d × d_k} V = X W_V W_V ∈ ℝ^{d × d_v} Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V Dimensions: QKᵀ ∈ ℝ^{n × n} (n²-size attention matrix — cost at long contexts) √d_k scales raw dot products to prevent softmax saturation at large d_k softmax row-wise → each row sums to 1 (weights over values) Output ∈ ℝ^{n × d_v}

Intuition: Q encodes "what I'm looking for," K encodes "what I contain," and V encodes "what I contribute." The dot product QKᵀ scores how relevant each key is to each query. Softmax normalises into weights. The output is a weighted sum of values — each token's new representation is an attention-weighted blend of all other tokens' value projections.

Why divide by √d_k ? With large d_k (e.g. 128), dot products QᵢKⱼ have variance proportional to d_k. Without scaling, these large values push softmax into near-zero gradient regions — the largest logit dominates with probability ≈1, all others ≈0, and gradients vanish. Dividing by √d_k keeps dot product variance constant at 1 regardless of d_k.

Causal Masking

During training (and in decoder-only models like GPT/LLaMA/Claude), each token may only attend to previous tokens — not future ones. This is implemented by adding −∞ to the upper triangle of QKᵀ before softmax, so e^{−∞} = 0 after softmax:

Masked_Score(i,j) = QᵢKⱼᵀ / √d_k if j ≤ i = −∞ if j > i After softmax, future positions receive attention weight 0.

Multi-Head Attention

A single attention head can only model one type of relationship at a time. Multi-head attention runs H independent attention operations in parallel, each with its own projection matrices, then concatenates and projects results:

head_h = Attention(Q W_Q^h, K W_K^h, V W_V^h) for h = 1, …, H W_Q^h ∈ ℝ^{d × d_k} where d_k = d/H (split model dimension across heads) W_K^h ∈ ℝ^{d × d_k} W_V^h ∈ ℝ^{d × d_v} where d_v = d/H MultiHead(Q,K,V) = Concat(head₁, …, head_H) · W_O W_O ∈ ℝ^{Hd_v × d} (output projection combining all heads) Example (LLaMA-3 70B): d=8192, H=64, d_k=d_v=128 Total parameters in MHA: 4d² = 4×8192² = 268M per layer

Different heads empirically specialise: some track syntactic dependencies, others co-reference, others domain-specific patterns. Head 3 in layer 15 of a large LLM might specialise in tracking which entity a pronoun refers to 200 tokens back.

Grouped Query Attention (GQA)

Standard MHA replicates K and V matrices for every head — expensive for KV cache. Grouped Query Attention (Ainslie et al., 2023, used in LLaMA-3, Mistral) groups Q heads and shares a single K, V per group:

G groups, H query heads, H/G key-value heads. KV cache size reduction: H/G × smaller (G=8 → 8× smaller KV cache) Quality impact: minimal — KV sharing loses little information at scale LLaMA-3 70B: H=64 query heads, G=8 groups → 8 KV heads KV cache reduced from 64× to 8× (8× memory saving for long contexts)

The Transformer Block

Each of the L transformer layers (blocks) applies two sub-layers in sequence, each followed by residual addition and layer normalisation:

x' = x + Attention(LN(x)) [multi-head self-attention + residual] x'' = x' + FFN(LN(x')) [feed-forward network + residual] LN = Layer Normalisation (pre-norm variant, used in modern LLMs) This is the "pre-norm" formulation; original 2017 transformer used post-norm.

Feed-Forward Network (FFN)

The FFN applies two linear projections with a nonlinearity in between. It constitutes ~2/3 of parameters in a transformer:

FFN(x) = W₂ · SiLU(W₁x) ⊙ (W₃x) [SwiGLU variant, used in LLaMA] W₁ ∈ ℝ^{4d × d}, W₂ ∈ ℝ^{d × 4d}, W₃ ∈ ℝ^{4d × d} Intermediate dim = 4d (or ≈2.67d for SwiGLU with same parameter count) FFN parameters per layer: 3 × d × 4d ≈ 12d² (SwiGLU has 3 weight matrices) Attention parameters per layer: 4d² Ratio: FFN ≈ 3× attention parameters

Positional Encoding

Self-attention is permutation-invariant — the same result regardless of token order. Positional encoding injects order information. Modern LLMs use Rotary Positional Embeddings (RoPE):

RoPE rotates the Query and Key vectors for position m by angle mθᵢ: Q_m = R(m) · Q where R(m) is a rotation matrix parameterised by position m K_n = R(n) · K After rotation: Q_m · K_nᵀ depends only on the relative position (m − n): Q_m · K_nᵀ = (R(m)Q) · (R(n)K)ᵀ = Q · R(m−n) · K Rotation angles: θᵢ = 1 / 10000^{2i/d} for dimension i Benefits: - Attention scores naturally decay with distance (cos(mθᵢ) behaviour) - Extrapolates to longer contexts than training (with YaRN or NTK scaling) - No learned parameters — mathematically principled

Scale and the Emergence of Capability

Model capability scales as a smooth power law with parameters, data, and compute — until it doesn't. Emergent abilities are qualitative capability jumps that appear discontinuously at specific scale thresholds, not predicted by interpolating from smaller models:

CapabilityApproximate emergence thresholdNotes
3-digit arithmetic~50M parametersNear-zero accuracy below, high above
Chain-of-thought reasoning~10B parametersImproves dramatically with scale
Multi-step word problems~30B parametersGPT-3 175B still limited; GPT-4 capable
Truthful calibration~50B+ parametersSmaller models confidently hallucinate more
In-context learning~1B+ parametersUsing examples in the prompt to solve new tasks

Mixture of Experts (MoE)

MoE replaces each FFN with E independent expert networks. A learned router network selects the top-k experts (typically k=2) for each token:

Router: g(x) = TopK(softmax(W_r · x), k) scores each expert for token x MoE-FFN(x) = Σ_{i ∈ TopK} g(x)_i · Expert_i(x) Total parameters: E × FFN_params Active parameters per token: k × FFN_params (only k experts fire) Mixtral 8×7B: 8 experts, 2 active → 46.7B total params, 12.9B active per token → inference cost of a 13B model, quality approaching a 70B model

Context Length and Its Challenges

The attention matrix QKᵀ ∈ ℝ^{n×n} scales quadratically with sequence length n. Memory and compute cost of attention:

Attention memory: n² × n_heads × sizeof(float) per layer At n=128,000 tokens, H=64 heads, BF16: = (128,000)² × 64 × 2 bytes ≈ 2.1 TB per layer — clearly infeasible Solutions: FlashAttention: Tile attention computation to stay within L2/SRAM. Does not reduce asymptotic complexity but avoids writing n×n matrix to HBM. Memory complexity: O(n) instead of O(n²). Speeds up attention 2–4×. Sliding window attention (Mistral): each token attends to W=4096 recent tokens only. O(nW) complexity. Loses global context. Ring attention: distribute the n×n attention matrix across GPUs in a ring. Each GPU computes a local block; pass K,V between GPUs in a ring. Scales to 1M+ tokens by adding GPUs.
FlashAttention implementation insight Standard attention materialises the full n×n attention score matrix to HBM (80 GB HBM at 3.35 TB/s). For n=32,768, this is 32,768² × 64 × 2 bytes ≈ 137 GB — far larger than HBM. FlashAttention-2 processes attention in tiles that fit in SRAM (20 MB on H100), never materialising the full matrix. The online softmax trick tracks the running normalisation across tiles without losing numerical stability.
