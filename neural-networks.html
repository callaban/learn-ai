Foundation

Neural Networks

The mathematical machinery behind deep learning — from a single artificial neuron to the forward and backward passes that drive learning in networks with billions of parameters.

The Artificial Neuron

A biological neuron integrates electrical signals from thousands of dendrites and fires an output along its axon if the total input exceeds a threshold. The artificial neuron is an algebraic abstraction of this process. Given a vector of n inputs x = [x₁, x₂, …, xₙ], the neuron computes a scalar output a in two steps:

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b = wᵀx + b a = f(z) where f is an activation function

Here w is the weight vector — the parameters the network learns — and b is the bias, a scalar offset that shifts the activation threshold. The pre-activation value z is a weighted sum: a dot product. The activation function f introduces nonlinearity; without it, a stack of neurons would collapse to a single linear transformation regardless of depth.

Why nonlinearity matters A composition of linear functions is itself linear: A(Bx) = (AB)x. No depth of purely linear layers can learn to classify XOR, fit a sine wave, or parse language. Nonlinear activations break this limitation, letting deep networks approximate any continuous function (by the Universal Approximation Theorem).

Activation Functions

The choice of activation function profoundly affects training dynamics. The dominant activation in modern networks is ReLU and its variants:

ReLU(z) = max(0, z) Leaky ReLU(z) = max(αz, z) where α ≈ 0.01 GELU(z) ≈ z · Φ(z) where Φ is the CDF of N(0,1) ≈ 0.5z(1 + tanh(√(2/π)(z + 0.044715z³))) SiLU(z) = z · σ(z) = z / (1 + e⁻ᶻ) [used in LLaMA, Mistral] Sigmoid σ(z) = 1 / (1 + e⁻ᶻ) ∈ (0, 1) [outputs/gates only] Softmax(z)ᵢ = eᶻⁱ / Σⱼ eᶻʲ [output layer, multiclass]

ReLU is computationally trivial (a single comparison), avoids the vanishing gradient problem of sigmoid/tanh at extremes, and empirically trains fast. GELU and SiLU are smooth approximations used in transformers because they empirically improve convergence on language tasks. Softmax converts a raw score vector (logits) into a probability distribution — the sum of all outputs equals 1.

Sigmoid / Tanh Problems

For |z| > 3, σ'(z) ≈ 0. When these near-zero gradients are multiplied through many layers via the chain rule, the gradient signal vanishes exponentially — parameters in early layers receive negligible updates. This is the vanishing gradient problem that prevented training deep networks until ReLU and residual connections arrived.

ReLU Problems

When z < 0, ReLU outputs exactly 0 and its gradient is 0. If a neuron consistently receives negative input across all training examples, it never receives a gradient and stops learning — a "dead ReLU." Leaky ReLU, GELU, and SiLU mitigate this by allowing a small nonzero output for negative inputs.

Network Architecture

Neurons are arranged into layers. The input layer holds the raw features. One or more hidden layers progressively transform the representation. The output layer produces the prediction. In a fully connected (dense) layer, every neuron in layer ℓ connects to every neuron in layer ℓ+1.

Using matrix notation, a single layer maps an input vector x ∈ ℝⁿ to an output vector a ∈ ℝᵐ:

a = f(Wx + b) W ∈ ℝᵐˣⁿ (weight matrix: m output neurons, n inputs each) b ∈ ℝᵐ (bias vector) f applied elementwise

A network with L layers computes:

a⁽⁰⁾ = x (input) a⁽ˡ⁾ = f⁽ˡ⁾(W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾) for l = 1, …, L ŷ = a⁽ᴸ⁾ (output)

Loss Functions

Training requires measuring how wrong the model's predictions are. A loss function L maps the model output ŷ and the true target y to a scalar. The network learns by minimising this scalar over the training set.

Mean Squared Error (MSE) — regression

LMSE = (1/n) Σᵢ (ŷᵢ − yᵢ)² ∂L/∂ŷᵢ = (2/n)(ŷᵢ − yᵢ) ← gradient fed into backprop

Cross-Entropy — classification

For a C-class problem with one-hot target vector y and softmax output ŷ:

LCE = − Σᶜ yᶜ · log(ŷᶜ) For the correct class c*: LCE = −log(ŷc*) ∂L/∂zᶜ = ŷᶜ − yᶜ ← combined softmax + cross-entropy gradient

The elegance of pairing softmax with cross-entropy is that the combined gradient is simply (ŷ − y) — clean, numerically stable, and fast to compute.

Next-Token Prediction Loss (Language Models)

L = − (1/T) Σₜ log P(xₜ | x₁, x₂, …, x_{t-1}; θ) where P(·) is the model's softmax distribution over V vocabulary tokens T is the sequence length, θ are the model parameters

Backpropagation

The forward pass computes the loss. Backpropagation efficiently computes every partial derivative ∂L/∂wᵢⱼ using the chain rule of calculus. For parameter w in layer ℓ, the gradient depends on every computation that follows w in the forward pass:

∂L/∂W⁽ˡ⁾ = ∂L/∂a⁽ˡ⁾ · ∂a⁽ˡ⁾/∂z⁽ˡ⁾ · ∂z⁽ˡ⁾/∂W⁽ˡ⁾ = δ⁽ˡ⁾ · (a⁽ˡ⁻¹⁾)ᵀ where δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾)ᵀ δ⁽ˡ⁺¹⁾ ⊙ f'(z⁽ˡ⁾) [error signal propagated back] ⊙ denotes elementwise multiplication

The computational trick is that backprop reuses intermediate values computed during the forward pass. A modern autodiff framework (PyTorch, JAX) records the computation graph during the forward pass and traverses it in reverse to accumulate gradients. No symbolic differentiation is required — just recursive application of the chain rule on primitive operations.

Memory cost of backprop To compute gradients, the activations a⁽ˡ⁾ at every layer must be stored until that layer's backward pass runs. For a 70B-parameter model training on long sequences, this activation memory can exceed 100 GB per GPU — often larger than the parameter memory itself. Gradient checkpointing trades recomputation for memory: only a subset of activations are stored; the rest are recomputed on demand during the backward pass.

Vanishing and Exploding Gradients

During backprop, the gradient at layer ℓ is multiplied by the Jacobian of every subsequent layer. If those Jacobians have spectral norm < 1 (as sigmoid and tanh do at saturation), the gradient shrinks exponentially with depth — vanishing. If the norm exceeds 1, it grows exponentially — exploding. ReLU has a constant gradient of 1 for positive inputs, which helps. Residual connections (adding the input directly to the output of a layer) create gradient highways that bypass this multiplicative chain.

Regularisation

Without constraint, a network with enough parameters will memorise training data instead of generalising — overfitting. Key regularisation techniques:

L2 Weight Decay

L_total = L_task + (λ/2) Σᵢ wᵢ² ∂L_total/∂wᵢ = ∂L_task/∂wᵢ + λwᵢ Effective update: w ← w(1 − ηλ) − η · ∂L_task/∂w

Weight decay penalises large weights, biasing the model toward simpler solutions. λ is a hyperparameter (typical value: 0.01–0.1 for large models).

Dropout

During training, each neuron's activation is set to zero with probability p (typically 0.1–0.5) and scaled by 1/(1−p) to maintain expected values. This prevents co-adaptation — neurons cannot rely on specific other neurons, forcing redundant representations. At inference, dropout is disabled.

Batch Normalisation

BN(x) = γ · (x − μ_B) / √(σ²_B + ε) + β μ_B = (1/m) Σᵢ xᵢ (batch mean) σ²_B = (1/m) Σᵢ (xᵢ−μ_B)² (batch variance) γ, β are learned scale and shift parameters ε ≈ 1e-5 for numerical stability

Batch norm re-centres activations to zero mean and unit variance at each layer, dramatically stabilising training of deep networks. Modern transformers use Layer Normalisation instead, which normalises across the feature dimension rather than the batch dimension — better suited to variable-length sequences and small batch sizes.

Parameter Count and Computational Cost

For a fully connected layer with n inputs and m outputs:

  • Parameters: m × n (weights) + m (biases) ≈ mn
  • FLOPs per forward pass: 2mn (mn multiplications + mn additions)

For a model with total parameter count P, training on D tokens:

Training compute ≈ 6PD FLOPs 6× = 2 (multiply-add) × 3 (forward + backward + parameter update) This is the Kaplan/Chinchilla approximation used to budget training runs.

A 70B parameter model (P = 7×10¹⁰) trained on 2 trillion tokens (D = 2×10¹²) requires approximately 8.4×10²³ FLOPs — 840 zettaFLOPs. An NVIDIA H100 delivers ~1,979 teraFLOPS at BF16, so this training run requires on the order of 12 million H100-hours — or roughly 1,400 H100-days at peak efficiency. Real clusters achieve 30–50% model FLOP utilisation (MFU), so actual time is 2–3× longer.

Key insight: parameters vs activations Inference requires loading model parameters once and computing activations per token. Training requires loading parameters AND storing all intermediate activations for backprop. At a batch size of 1,024 and sequence length of 4,096, activation memory can be 5–10× larger than parameter memory per GPU.
